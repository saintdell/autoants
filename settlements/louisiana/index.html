How we pick and check them

  • Only settlements taking claims now. A lawsuit that hasn't settled, a settlement with no claim form yet, and a program that pays automatically aren't listed.
  • Only classes that include businesses and reach Louisiana: nationwide classes, or classes whose state list names Louisiana.
  • Only the official site. We read each settlement on the site the court notice or the settlement administrator names, and link only to it. News sites and lead pages that advertise settlements are never the claim site. Type the address in yourself if you prefer.
  • No dollar estimates. We print a payment figure only when the official notice publishes one, and then we quote it.
  • Nothing to sell here. No forms, no sign-ups, no paid or tracked links. We earn nothing if you file.
